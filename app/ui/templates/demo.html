What does this demo demonstrate?

This demo runs the real KnowledgeOS retrieval, reranking, citation validation and grounding pipeline — the same code a production deployment runs, against a fixed corpus of synthetic company policy documents. Eight questions below have a hand-verified answer, checked against the same citation and grounding validation the real pipeline always runs. Any other question still runs the real retrieval and reranking pipeline, and is answered honestly if no verified answer exists for it — never a guess.

This demo uses a fixed set of synthetic company policy documents and hand-verified answers. No sign-in or API key is required. Nothing you type is used for anything beyond this one query, no real company data appears anywhere in this demo, and this page has no upload, document-management or feedback controls.
